# T2.1 · Unit-test the MCP server

**Status:** not started · **Tier:** 2 · **Cost:** ~1 day

## Why

The server is 1,723 lines across 7 modules. `scripts/smoke-tools.mjs` exercises the 10
tools over stdio — 35 assertions, all passing — and there are no unit tests for any
internal module. `src/` has never been reviewed, so unlike the rest of this plan this tier
is honestly **unassessed** rather than assessed-and-fine.

## Order, highest risk first

1. **`validator.ts` (303 lines) — the enforcement brain.** It decides what counts as a legal
   token. A false negative here silently permits raw colour into every page the server
   generates, which defeats the entire design system. Table-driven tests: every rule, plus
   adversarial near-misses — a real token name with a doubled trailing letter, an invented
   suffix on a real prefix — and valid core Tailwind utilities, which must pass.
2. **`scaffold.ts` (508 lines)** — the largest module. Generated pages must pass
   `validate_code` *and* the preview-page rule (`audit-full` E3: a preview may not redefine
   tokens). Assert both on real generated output.
3. **`editor.ts` (236)** — `edit_page` add and remove round-trip without corrupting a page.
4. **`docIndex.ts` (143)** and **`cheatsheet.ts` (65)** — search returns the documented answers.
5. **`project.ts` (90)** — path handling. Assert it cannot write outside its configured
   project directory, including via `..` traversal.
6. Golden-file tests for `build_page` output, so scaffold changes are reviewable as diffs.

## Acceptance criteria

- [ ] Each module above has unit tests, `validator.ts` first
- [ ] The validator suite includes negative cases, not only positive ones
- [ ] Golden files committed for generated-page output
- [ ] Runs in CI

## Verify

```bash
npm run test:unit && npm run smoke
```

## Prove it fails

- [ ] Weaken one validator rule so a raw colour class passes, confirm the negative case
      fails, then revert. This is the single most important deliberate failure in the repo:
      it is the test that the enforcement itself still enforces
