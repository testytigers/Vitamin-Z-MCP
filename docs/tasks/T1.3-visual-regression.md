# T1.3 · Visual regression

**Status:** not started · **Tier:** 1 · **Cost:** ~half a day

## Why

Chromium is available and nothing renders. Token changes are invisible until a human looks,
and nobody has looked yet.

The compact-density split is the case for this task: a 12px button label sitting beside a
14px tab is obvious in a screenshot and completely invisible to a token audit. So was the
badge, select and toggle-group padding that stayed at default size in compact mode.

## Acceptance criteria

- [ ] Playwright screenshots of `ds-shadcn/verify.html` in all four mode combinations ×
      both densities
- [ ] Per-component snapshots, so a token change surfaces as a picture in the diff
- [ ] Baselines committed, and a documented way to update them intentionally
- [ ] PRs require a human to approve pixel changes
- [ ] Uses the repo's existing Chromium rather than downloading its own

## Verify

```bash
npm run test:visual
```

## Prove it fails

- [ ] Change one chart categorical token by one step, confirm the snapshot diff flags it,
      then revert
- [ ] Switch the compact density block to shrink control type again, confirm the compact
      snapshots change — this is the exact regression `audit-full` B6 guards, so the two
      checks should agree

## Notes

Do this *after* `HUMAN-TEST.md` §1. Baselines captured before a human has confirmed the
design is correct would freeze whatever is currently wrong.
